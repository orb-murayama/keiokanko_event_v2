## 在庫管理フロー

```
┌─────────────────────────────────────────────────────────────────┐
│                   Stock Management Flow                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  在庫タイプ                                                      │
│  ┌────────────────────┐       ┌────────────────────┐           │
│  │  Individual Stock  │       │   Shared Stock     │           │
│  │  (個別在庫)        │       │   (共有在庫)       │           │
│  │                    │       │                    │           │
│  │ product_stocks     │       │ shared_stock_pools │           │
│  │ • stock_id         │       │ • stock_id         │           │
│  │ • stock_type:      │       │ • stock_type:      │           │
│  │   'individual'     │       │   'shared'         │           │
│  │ • date             │       │ • date             │           │
│  │ • stock            │       │ • total_stock      │           │
│  │ • booked           │       │ • booked           │           │
│  └────────────────────┘       └────────────────────┘           │
│           │                            │                         │
│           └────────────┬───────────────┘                         │
│                        ▼                                         │
│  ┌─────────────────────────────────────────────────────┐       │
│  │          Booking Process                            │       │
│  │                                                      │       │
│  │  1. ユーザーが商品を選択                            │       │
│  │     → stock_id + stock_type を取得                 │       │
│  │                                                      │       │
│  │  2. 予約作成                                         │       │
│  │     → booking_items に保存                          │       │
│  │     → stock_id, stock_type を記録                  │       │
│  │                                                      │       │
│  │  3. 在庫減算                                         │       │
│  │     if (stock_type === 'individual')                │       │
│  │       → product_stocks.booked++                     │       │
│  │     else                                             │       │
│  │       → shared_stock_pools.booked++                 │       │
│  │                                                      │       │
│  │  4. 予約変更・キャンセル                            │       │
│  │     → booking_items.stock_type を参照               │       │
│  │     → 正しいテーブルで在庫を戻す                    │       │
│  └─────────────────────────────────────────────────────┘       │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```
